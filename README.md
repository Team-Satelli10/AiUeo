# AiUeo
好きなキャラクターと自由に交流しよう！

※Genie-TTSを非公式でモバイル版に対応させました。不具合が発生するかもしれません。不具合が発生した場合は些細なことでもかまいませんのでご報告をお願いします。  

---
現在シングルマシンタイプはMacOS,Windows11、クラウドタイプはAndroid,macOS,windows11に対応予定。Linux,iOS,iPadOS環境も予定していますが、時間が掛かりそうです。

## 動作要件(シングルマシン)  
### Windows  
・CPU Intel Core i7 10th Gen~ or AMD Ryzen 7 5000番台~  
・RAM DDR5 32GB~  
・GPU Nvidia Geforce RTX3000番台~ or AMD Radeon RX6000番台   
・VRAM 16GB~ (ローカルLLMのサイズによって変化します。)  
・Storage 空き容量128GB~  

### macOS  
・CPU Apple M3 Pro~  
・RAM 24GB~ (ローカルLLMのサイズによって変化します。)  
・Storage 空き容量128GB~  

## 最低動作要件(クラウドタイプ:サーバー)  
### Windows  
・CPU Intel Core i5 10th Gen~ or AMD Ryzen 5 5000番台~  
・RAM DDR4 16GB~  
・GPU Nvidia Geforce RTX2000番台~ or AMD Radeon RX5000番台   
・VRAM 8GB~ (ローカルLLMのサイズによって変化します。)  
・Storage 空き容量32GB~  

### macOS  
(おすすめ:mac mini, mac studio, mac pro)  
・CPU Apple M2~  
・RAM 16GB~ (ローカルLLMのサイズによって変化します。)  
・Storage 空き容量32GB~  

## 最低動作要件(クラウドタイプ:クライアント) 
### AndroidOS  
・CPU Snapdragon 8 Gen3またはそれ以上の性能を持つSoC  
・RAM 12GB~(仮想メモリ使用不可)  
・Storage 空き容量32GB~  
  
### iOS  
iPhone Air または iPhone17 Proシリーズ
(RAM容量12GB以上)  
  
### iPadOS  
iPad Pro M4 (1tb~) または iPad Pro M5  
(RAM容量12GB以上)  

## ダウンロード

zipファイル→完成後に公開します。  
  
クラウドのみ(クライアント):
